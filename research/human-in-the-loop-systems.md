# Human-in-the-Loop Systems

## Thesis

Machines continuously collect, structure, enrich, monitor, and act upon information while humans retain authority over consequential interpretation, intervention, and decisions.

## Questions

- Where should automation stop?
- Which decisions require human authority?
- How should exceptions be routed?
- How should uncertainty be represented?
- How should humans audit automated execution?
- What feedback should return to the system?

## Architecture

`SOURCE → RAW → NORMALIZE → ENRICH → SIGNAL → INTELLIGENCE → DECISION → WORKFLOW → AUTOMATION → OUTCOME → FEEDBACK`
