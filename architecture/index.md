# Systems Architecture

## Positioning
**Business Systems Architecture · Data Architecture · Workflow Architecture**

## Core Question
What information must move, between which systems, under what conditions, so that the organization can make the right decision and execute the right action?

## Architecture Stack
Business problem → Information model → Data model → Systems → Integrations → Workflow → Intelligence → Automation → Human authority → Measurement → Feedback

## Human Authority
Automation controls pace. Human-in-the-loop controls context, consequential judgment, exceptions, and accountability.
