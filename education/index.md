# Learning Systems

## Caphè Learning Architecture
`KNOWLEDGE → LESSON → VIDEO → EXERCISE → ARTIFACT → ASSESSMENT → CAPABILITY → APPLICATION → FEEDBACK`

## Audiences
High school 9–12 · Community college · University · Professors / educators · Corporate teams · Professional learners

## Core Curriculum
Information Systems Literacy · Data Literacy · Systems Thinking · Workflow & Automation · Databases · AI & Intelligent Systems · Digital Identity / Privacy / Security · Information Systems & Work · Systems Architecture

## High School Financial Literacy System
A dedicated applied-learning track for grades 9–12: budgeting, credit, saving and investing basics, and financial decision-making, taught with the same concept-and-practice discipline as the rest of the Caphè Learning Architecture — integration targeted for 2027, part of the Applied Learning & Information Workforce Systems research program.
