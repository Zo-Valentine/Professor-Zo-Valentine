# Data Engineering

## Positioning
**Data Engineering for Operational Workflows**

I design data systems that turn fragmented operational information into reliable, usable infrastructure.

## Core Services
Data integration · API integration · ETL / ELT · data cleaning · normalization · entity resolution · data structure design · data warehouses · data APIs · reporting pipelines · data quality · alternative data infrastructure · historical state / event systems · observability

## Architecture
`SOURCE → INGEST → RAW → NORMALIZE → RESOLVE → MODEL → SERVE`

## Business Systems Connection
Data engineering is not treated as an isolated technical function. The objective is to make data useful to workflows, intelligence, decisions, and measurable outcomes.
