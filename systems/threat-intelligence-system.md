# Threat Intelligence System

**Distributed threat signals → intelligence → human investigation**

Status: Research / prototype

## Purpose
Collect distributed open-web, breach, identity, and dark-web signals; resolve entities and patterns; produce investigation-oriented intelligence for human review.

## Architecture
`SIGNALS → REGISTRY → NORMALIZE → ENTITY RESOLUTION → PATTERN SYNTHESIS → RISK / SCENARIO → INTELLIGENCE → HUMAN INVESTIGATOR → CASE WORKFLOW → FEEDBACK`

## Modules
Signal collection · Source registry · Normalization · Entity resolution · Behavioral pattern synthesis · Scenario/risk modeling · Evidence management · Investigation workflow · Case tracking · Reporting

## Human Boundary
The system supports investigation and decision-making. It should not make unsupported accusations, determine guilt, or replace legal/investigative judgment.
