# Portfolio Interface Model

## Homepage
Identity → Thesis → Capability → Systems → Architecture → Research → Book → Start

## Navigation
Work · Research · Systems · Services · Books · Education

## Visual grammar
Large editorial typography · thin rules · dense system diagrams · neutral paper/black palette · one controlled accent · no generic SaaS gradients.

## Content grammar
Problem → System → Evidence → Outcome → Reusable Pattern

## Evidence rule
Do not claim a result until evidence exists. Use explicit status labels: Research / Prototype / Active / Deployed.

## Growth model
Create system → add architecture → add evidence → add case study → link from Work → publish.
